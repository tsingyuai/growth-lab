# title-patterns · 公众号标题

公众号标题优先保证“清楚、有价值、可转发”，但必须有点击钩子。可以学习小红书标题的痛点、反差、结果承诺和数字结构，不照搬情绪化口吻。

## 可用模式

| 模式 | 结构 | 示例骨架 |
|---|---|---|
| 痛点 + 方法 | 读者卡点 + 本文给出的做法 | `{任务}怎么做才靠谱？先把{关键步骤}跑成一条流程` |
| 问题直给 | 直接写读者会问的问题 | `{任务}怎么从 0 做到可交付` |
| 任务 + 结果 | 一次完整任务 + 可见产物 | `用一个工作区完成一次{任务}：从{起点}到{产物}` |
| 方法清单 | 数字 + 判断维度 | `开始{任务}前，先想清楚这 4 个问题` |
| 功能更新 | 产品名 + 读者得到的新结果 | `{产品}更新：{读者现在能做到的事}` |

## 不推荐

- 夸张绝对化：`最好用`、`100% 不出错`、`彻底解决`。
- 把辅助写成替代：`一键搞定全部`、`帮你全部做完`。
- 小红书口吻直接搬：`救命`、`封神`、`姐妹们冲`。

## 自检

- 标题能让读者知道读完会得到什么吗？
- 有没有释放一个明确钩子：痛点、反差、结果、数字或物证？
- 能不能回答“用户能获得什么价值 / 解决什么问题”？
- 有没有承诺产品做不到的结果？
