# 质量检查

## 渲染前

- 标题、caption 和上图文字已完成 DAI。
- 宣称已对照当前产品证据。
- image plan 已审定，所需素材齐全。
- 合规和禁用表达脚本退出码均为 0。

## 逐图检查

以全尺寸打开每张最终图片，检查：中英文、数字、引用和标点逐字准确；卡片顺序与 image plan 一致；没有多余文字、水印、异常物体、假 UI 或虚构数据；截图像素清楚且未被重画；裁切、边距、对比和层级适合移动端；参考版式没有复制受保护的正文或品牌；生成元素没有遮挡事实证据。

单卡失败时只做一轮针对性修正，再重新检查。连续生成仍无法保留大量精确内容时，切到确定性本地渲染。

## 整帖检查

- 封面能吸引点击，但没有无依据承诺。
- 顺序从钩子走向场景、证据和有用结论。
- 不同卡片没有换装饰重复同一结论。
- caption 与卡片中的事实和术语一致。
- 产品身份与商业角色诚实清楚。
- 平台要求的 AI 披露留到发布时正确处理。

## 最终自动检查

```bash
python3 executors/xhs-render-cards/scripts/check-banned-phrases.py <post-dir>
python3 executors/xhs-render-cards/scripts/check-compliance.py <post-dir>
```

把通过/失败和人工检查结果记录到 `PROCESS.md`。不得自动发布。
