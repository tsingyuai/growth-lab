# 质量检查

## 渲染前

- 标题、caption 和上图文字已完成 DAI。
- 宣称已对照当前产品证据。
- image plan 已审定，所需参考图与真实浏览器截图齐全。
- 合规和禁用表达脚本退出码均为 0。
- 生产模式与 image plan 一致；确定性渲染保留精确文字和真实截图，可分离图层不含文字或 UI，完整效果只使用已验证的单一视觉参考。
- 真实产品 UI、logo、引用和数据来自产品自有证据，没有把模型生成界面冒充真实截图。
- 没有因为文字多、中英文混排、精确排版或网页视觉复杂而绕开生图模型，也没有占位符或代码贴图步骤。

## 逐图检查

以全尺寸打开每张最终图片，检查：中英文、数字、引用和标点逐字准确；卡片顺序与 image plan 一致；没有多余文字、水印、异常物体、假 UI 或虚构数据；截图中的产品名称、结构、关键文字和界面关系与源图一致；裁切、标注、边距、对比和层级适合移动端；参考版式没有复制受保护的正文或品牌；生成元素没有遮挡事实证据。

单卡失败时做针对性重生并重新检查。只有实际生成结果反复出现错误时才考虑缩短文案或请求用户调整内容；不得预设模型无法处理文字，也禁止切到 HTML、SVG 或代码模板渲染。

## 整帖检查

- 封面能吸引点击，但没有无依据承诺。
- 顺序从钩子走向场景、证据和有用结论。
- 不同卡片没有换装饰重复同一结论。
- caption 与卡片中的事实和术语一致。
- 产品身份与商业角色诚实清楚。
- 全文只有一个鲜明立场，没有客观综述、兼顾两面、退缩词或防御性表达。
- 有风险或无证据的 claim 已整句删除，没有通过免责声明保留弱化版本。

## 最终自动检查

```bash
python3 executors/xhs-render-cards/scripts/check-banned-phrases.py <post-dir>
python3 executors/xhs-render-cards/scripts/check-compliance.py <post-dir>
```
