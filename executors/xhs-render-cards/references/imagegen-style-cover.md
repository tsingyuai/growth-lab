# 封面风格 Prompt 模板

根据调用方 loop 提供的品牌事实填写所有方括号。实际 prompt 中不得残留占位符。

```text
生成一张 3:4 竖版小红书封面，主题是[品牌/产品/选题]。

风格：[品牌形容词与视觉参考]。移动端信息层级清楚，装饰克制，留白充分，中文排版达到编辑设计品质。

配色：
- 背景：[色值与质感]
- 主强调色：[色值与用途]
- 辅助色：[色值与用途]
- 主文字：[色值]
- 次文字：[色值]

内容：
- 顶部场景标签：[准确文字]
- 主钩子：[准确文字]
- 补充说明：[准确文字]
- 证据/信任锚：[准确文字]
- 可选品牌账号：[准确文字或省略]

硬约束：
- 所有指定文字必须逐字准确，不得增加其他文字。
- 不得出现水印、假 logo、假 UI、虚构数据或无关装饰。
- 不得使用 DAI SOP 禁止的模型套话和否定公式。
- 标题在信息流缩略图尺寸下仍然清楚。
- 只能使用已提供的品牌身份，不得自行推断 logo 或账号。
```

指定文字出现错误时，强化逐字文字约束并针对性重生。不得因为中文、英文、文字数量或排版复杂而改用 SVG、HTML 或代码模板。
