# Xiaohongshu visual production additions

Read the canonical [visual production contract](../../render-social-card-pack/references/visual-production-contract.md) and [effect-first production contract](../../render-social-card-pack/references/effect-first-production.md) completely. Apply these Xiaohongshu additions:

- default canvas: 1080x1440 PNG in RGB or RGBA;
- store formal candidates only under `render/`;
- keep analysis-only references, raw model outputs, and effects outside publishable assets;
- require one validated primary visual reference when external visual research is used;
- keep the final caption, card order, image list, and target account in the downstream publishing manifest, not in the visual package approval.
