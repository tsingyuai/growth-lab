# 内容卡风格 Prompt 模板

根据已审定的 image plan 和当前品牌事实填写方括号。

```text
生成一张 3:4 竖版小红书内容卡，与[品牌/产品/选题]已审定封面属于同一套视觉系统。

风格与配色：
- 延续封面的字体、配色和留白节奏；
- 根据卡片职责改变构图，但不改变品牌身份；
- [主强调色]只少量使用，[辅助色]只用于元数据或信任锚。

卡片职责：[场景 / 解释 / 证据 / 对比 / 结论]
准确上图文案：
- 标签：[文字或省略]
- 标题：[文字]
- 正文/条目：[按顺序列出准确文字]
- 证据说明：[文字或省略]
- 可选品牌账号：[准确文字或省略]

硬约束：
- 所有指定文字必须逐字准确，不得增加其他文字。
- 不得出现水印、假 logo、假 UI、虚构数字或页码装饰。
- 生图模型负责完整视觉效果；若整体效果通过但精确文字仍有错误，预留或识别替换区，再由 HTML、SVG、Canvas 或 Pillow 定点替换，不重新设计整张卡片。
- 图片内不出现免责声明、局限说明或防御性表达；有风险的 claim 直接删除。
- 不得使用 DAI SOP 禁止的表达。
```

涉及事实 UI 时，让模型生成完整效果与明确的空白/色键截图区，再用确定性合成工具贴入真实浏览器截图。即使使用 `close-replication`，真实 Product UI 也不得经过模型重绘；模型 reference 只负责复现已确认的版式几何。
