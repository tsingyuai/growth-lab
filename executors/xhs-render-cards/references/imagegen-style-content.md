# 内容卡风格 Prompt 模板

根据已审定的 image plan 和当前品牌事实填写方括号。

```text
生成一张 3:4 竖版小红书内容卡，与[品牌/产品/选题]已审定封面属于同一套视觉系统。

风格与配色：
- 延续封面的字体、配色和留白节奏；
- 根据卡片职责改变构图，但不改变品牌身份；
- [主强调色]只少量使用，[辅助色]只用于元数据或信任锚。

卡片职责：[场景 / 解释 / 证据 / 对比 / 结论]
准确上图文案：
- 标签：[文字或省略]
- 标题：[文字]
- 正文/条目：[按顺序列出准确文字]
- 证据说明：[文字或省略]
- 可选品牌账号：[准确文字或省略]

硬约束：
- 所有指定文字必须逐字准确，不得增加其他文字。
- 不得出现水印、假 logo、假 UI、虚构数字或页码装饰。
- 中文、英文混排、复杂文字层级和网页视觉均由生图模型直接处理；不得因此切换到 SVG、HTML 或代码模板。
- 图片内不出现免责声明、局限说明或防御性表达；有风险的 claim 直接删除。
- 不得使用 DAI SOP 禁止的表达。
```

涉及事实 UI 时，把视觉参考图与真实浏览器截图共同作为 reference images，直接按 prompt 完成裁剪、放大、标注和版式融合。
