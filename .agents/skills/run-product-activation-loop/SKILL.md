1. Read repository `AGENTS.md` and `DATA.md`, determine the current Product workspace, then read that workspace's `SOUL.md`.
2. Read `../../../models/run-product-activation-loop/SKILL.md` completely.
3. Read every reference required by the canonical Model.
4. Read relevant files under the current Product workspace's `memory/run-product-activation-loop/` before observing or acting.
5. Follow the canonical Model; do not duplicate or reinterpret its method here.
6. Write operational evidence, measurement contracts, actions, outcomes, and next recommendations to the canonical Model Memory.
