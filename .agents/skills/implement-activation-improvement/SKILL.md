# Implement an activation improvement

1. Read repository `AGENTS.md` and `DATA.md`, determine the current Product workspace, then read its `SOUL.md`.
2. Read `../../../executors/implement-activation-improvement/SKILL.md` completely and read its experiment-design reference when real-user comparison or rollout is involved.
3. Require the owning Model's persisted evidence, measurement contract, approved scope, Product repository, and rollback boundary.
4. Follow the canonical Executor and the Product repository's own instructions.
5. Write implementation evidence to the owning Model Memory. Do not deploy or begin live exposure without separate approval.
