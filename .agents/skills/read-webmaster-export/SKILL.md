1. Read repository `AGENTS.md` and `DATA.md`, determine the current Product workspace, then read its `SOUL.md`.
2. Read `../../../collectors/read-webmaster-export/SKILL.md` completely.
3. Follow that canonical Collector method and store raw private data according to the team's retention policy.
4. Return normalized, scoped evidence to the calling SEO Model or Executor.

Keep export interpretation methodology only in the canonical Collector.
