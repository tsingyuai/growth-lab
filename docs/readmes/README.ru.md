## Зачем нужен Growth Lab

Большинство AI-инструментов для роста решают только одну часть задачи: создают тексты, изучают конкурентов, публикуют контент или показывают аналитику. Контекст продукта теряется между сервисами, а решения остаются разбросаны по дашбордам, документам, промптам и ручным процессам.

Growth Lab превращает рост в непрерывный цикл обучения:

```text
Понять продукт → Определить пользователей и рынки
→ Изучить каналы и контент → Сформировать стратегию
→ Создать и распространить → Оценить результат → Учиться и корректировать
```

Growth Lab использует Codex и Claude Code как Runtime. Сессия служит плоскостью управления, Skills содержат методы роста, Clients дают доступ к внешним действиям, а файловая система хранит долгосрочную память.

## Чем Growth Lab отличается

- **Полный цикл роста:** от поиска возможности до исполнения, измерения и следующего решения.
- **Работа на естественном языке:** задавайте цели, получайте готовый результат, оставляйте обратную связь и продолжайте цикл.
- **Связь данных, методов и действий:** Agent собирает доказательства, применяет метод, действует и использует результат в следующем цикле.
- **Открытый код и ваши данные:** контекст продукта, операционные данные, Memory и материалы остаются в вашем рабочем пространстве.

## Начало работы

```bash
git clone https://github.com/tsingyuai/growth-lab.git
cd growth-lab
```

Откройте каталог в Codex или Claude Code и опишите нужный результат:

```text
Изучи этот продукт и запусти его первый цикл роста.
Проанализируй последние результаты и выполни следующее действие.
```

Runtime читает доступные Models, формирует необходимый контекст, вызывает подходящие Collectors и Executors и сохраняет доказательства, результаты и следующие шаги. [Onboarding Skill](../../models/onboard-growth-lab/SKILL.md) проверяет зависимости через естественный язык.

## Доступные возможности

| Название | Описание | Наблюдаемый результат |
|---|---|---|
| [Цикл роста SEO-страниц](../../models/run-seo-page-loop/SKILL.md) | Изучает реальные поисковые запросы и создаёт полезные страницы, ведущие к продукту. | Индексация новых страниц за 1–2 дня; показы и клики выросли на 1000 % по 7-дневному среднему. |
| [Цикл копирования и анализа Xiaohongshu](../../models/xhs-replicate/SKILL.md) | Координирует сбор, тексты, изображения, рендеринг, проверку требований и анализ результата. | До 4000+ лайков/сохранений и 700+ комментариев у одной публикации; публикация остаётся ручной. |

Результаты зависят от продукта, домена, спроса, качества страниц, авторитета сайта и периода наблюдения.
