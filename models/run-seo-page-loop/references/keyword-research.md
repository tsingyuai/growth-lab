# Keyword research

## Build the opportunity space

Start from the user's job and expand across:

- core concepts;
- scenario × object combinations;
- action and outcome phrases;
- tools and format conversions;
- templates, examples, checklists, and resources;
- competitor and alternative names;
- questions, concerns, comparisons, and failure modes.

Use the live web to discover the language users already use. Treat autocomplete, related searches, SERP titles, communities, product reviews, support conversations, and internal search terms as evidence with different strengths.

## Validate demand

Use Bing Webmaster `GetKeywordStats` for comparable weekly impression history when an API key is available. Keep each batch at 20 terms or fewer and cool down between batches. Include a known-volume control term when validating a large set.

Interpretation:

- Compare head terms with head terms and compound terms with compound terms.
- Treat exact impressions as a comparable floor for demand.
- Treat an empty response as unavailable data, then triangulate with live SERPs and other evidence.
- Use peak-to-average differences to identify seasonality and schedule publication early enough for discovery.
- Judge intent before volume. A high-volume query earns a page only when the product can satisfy its task.

## Select the page

Choose from five signals:

1. observable demand;
2. clear search intent;
3. product ability to satisfy the task;
4. a meaningful information or experience gap in current results;
5. a credible path from the page to a product outcome.

Save the evidence and decision in whatever file shape makes the comparison easy to inspect.
