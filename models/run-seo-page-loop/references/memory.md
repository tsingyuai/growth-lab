# SEO loop Memory

Use `memory/run-seo-page-loop/` as the persistent memory for this Model.

## Before observation

Read the recent Memory entries and any older entries relevant to the current page, query family, market, or action. Recover:

- what was observed and when;
- what action was taken;
- what outcome followed;
- what the previous analysis concluded;
- which next actions remain relevant.

Treat earlier conclusions as historical judgments. Re-evaluate them against current evidence.

## After observation, action, or review

Write the useful evidence and interpretation to a date- or timestamp-prefixed file. Choose Markdown, JSON, CSV, HTML, or another readable format according to the task.

Make these facts understandable in the file:

- collection time and analysis period;
- source and page or query scope;
- important values and changes;
- interpretation and confidence;
- action taken during the run;
- observed outcome when available;
- recommended next action and supporting evidence.

Link to earlier Memory files when the current result confirms, updates, or overturns them.

## Keep methodology in the Model

When evidence reveals a better way to research keywords, design pages, generate images, submit URLs, or evaluate performance, edit this Model's `SKILL.md` or references directly. Record the operational evidence in Memory and the improved method in the Model. Do not store a backlog of methodology-change suggestions in Memory.
