# SEO page measurement

## Read the signals

Use Bing Webmaster page and query data after the page has had time to be crawled and shown. Compare periods with similar length and seasonality.

Analyze:

- indexed and crawl status;
- impressions and the queries producing them;
- clicks and click-through rate;
- average impression and click positions;
- changes after page or snippet updates;
- on-page product actions, activation, revenue, or another outcome relevant to the page;
- AI citations, cited pages, and grounding queries when Bing AI Performance is available.

## Diagnose by layer

- Discovery: Bing has not crawled or indexed the intended canonical URL.
- Demand: the chosen query family produces little observable demand.
- Ranking: impressions exist while positions remain weak.
- Snippet: positions are competitive while click-through rate remains weak.
- Intent: visitors arrive through queries the page resolves poorly.
- Content: competing pages provide stronger evidence, utility, freshness, or clarity.
- Conversion: the page satisfies the search but creates little product movement.

## Produce the review

Generate an HTML review when visual comparison improves the decision. Tailor it to the page and available evidence. Useful views may include a period comparison, query table, position distribution, page outcomes, annotated findings, and recommended next action.

Create the HTML directly in the workspace and open it with the Runtime browser. Preserve source files beside it when they help future analysis. Let the current question determine the data shape and visualization.
