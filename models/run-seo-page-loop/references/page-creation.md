# Page creation

## Match the page shape to intent

Infer the expected page shape from current results:

- tool intent → working tool or direct product action;
- template/resource intent → browsable collection with useful previews;
- how-to intent → complete guide with concrete steps and examples;
- comparison intent → explicit criteria, evidence, and tradeoffs;
- solution intent → problem-specific landing page with proof and a real path to action.

Use a hybrid when the product can fulfill the task directly: satisfy the informational expectation, then expose the product action at the moment it becomes useful.

## Create information gain

Add material that helps the visitor act or decide:

- firsthand product evidence;
- original examples and counterexamples;
- specific quality criteria;
- analysis of real data;
- downloadable or copyable artifacts;
- authoritative primary sources;
- constraints, edge cases, and failure modes.

Keep facts traceable. Use clear ownership and update signals. Write short, direct sentences. Give each section one distinct job.

## Ship a complete page

Adapt these elements to the product framework and page type:

- final title and meta description;
- one canonical URL;
- Open Graph and social image metadata;
- relevant schema.org structured data;
- descriptive heading hierarchy;
- useful main content and clear product action;
- contextual internal links;
- sitemap participation;
- source links and visible update information;
- responsive, accessible images with alt text and dimensions.

Use existing project patterns. Run the project's own SEO and build checks.
